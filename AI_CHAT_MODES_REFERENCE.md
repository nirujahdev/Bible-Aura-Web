# ✦ Bible Aura AI Chat Modes - Complete Reference

This document provides a comprehensive overview of all AI chat modes and their response structures in Bible Aura.

---

## 📋 **THE 6 MAIN AI CHAT MODES**

### 1. 💬 **AI Chat Mode** (`chat`)
**Purpose:** Fast conversational assistant for Bible-related topics and spiritual guidance  
**Word Limit:** 80 words (optimized for speed)  
**Tone:** Warm, encouraging, conversational

#### Response Structure:
```
✦ [Direct answer in 1-2 sentences]
[Scripture reference if relevant]
[Brief encouragement or question]
```

#### Key Requirements:
- Start with orange ✦ icon (no background shapes)
- Maximum 80 words for fast responses
- Direct, conversational answer
- Include scripture reference when relevant
- End with brief encouragement
- Use ↗ for sections, • for points when needed
- No complex theological jargon
- Clean formatting: ✦ ↗ • only, no hashtags or asterisks

#### Example:
```
✦ Jesus wept in John 11:35 because He felt genuine compassion for Mary and others mourning Lazarus' death. Even knowing He would raise Lazarus, Jesus showed His full humanity and empathy. His tears remind us that God understands our grief. How does knowing Jesus feels your pain comfort you?
```

---

### 2. 📖 **Verse Analysis** (`verse`)
**Purpose:** Deep, structured examination of specific Bible verses with accurate biblical foundation  
**Tone:** Scholarly, reverent, biblically accurate

#### Response Structure (5 Sections):
```
✦ VERSE ANALYSIS: [Verse Reference]

↗ Verse
[Complete verse text with reference and key term definitions]

↗ Historical Context
[When and where it was written, original audience, cultural setting]

↗ Theological Doctrine
[Core biblical doctrines and theological significance]

↗ Cross Reference
[3-4 related Bible verses that support or expand the meaning]

↗ Summary
[Concise summary of the verse's main message and application]
```

#### Key Requirements:
- Start with orange ✦ icon for main title only
- Use ↗ for section headers exactly as specified
- Use • for bullet points within sections
- Base all information on biblical sources and orthodox interpretation
- Include specific biblical references with chapter and verse
- Maintain theological accuracy and biblical authority
- No modern theological speculation - stick to biblical truth

---

### 3. 🌱 **Parable Study** (`parable`)
**Purpose:** Break down Jesus' parables into understandable lessons  
**Tone:** Teaching, clear, application-focused

#### Response Structure (4 Components):
```
✦ PARABLE: [Name] ([Reference])

↗ The Story
[Brief retelling of the parable with key characters and events]

↗ Original Audience & Context
[Who Jesus was speaking to and why, historical/cultural context]

↗ Core Spiritual Lesson
[The main truth Jesus was teaching, why it was important]

↗ Modern-Day Example
[How this applies to contemporary life with relatable scenario]
```

#### Key Requirements:
- Start with orange ✦ icon for parable title
- Always include the parable reference
- Use ↗ for sections and • for bullet points only
- Keep modern examples relatable and appropriate
- Focus on Jesus' intended lesson
- Clean structure with ✦ ↗ • symbols

---

### 4. 👤 **Character Study** (`character`)
**Purpose:** Comprehensive character studies with life lessons  
**Tone:** Biographical, inspiring, balanced

#### Response Structure (4 Sections):
```
✦ CHARACTER PROFILE: [Name]

↗ Quick Overview
[Who they were, time period, location, key verse, one-sentence summary]

↗ Timeline & Key Events
[3-5 most important events in chronological order with scripture references]

↗ Lessons for Today
[2-3 key life lessons with both positive and negative examples]

↗ Key Scripture References
[3-5 essential verses/passages about this character]
```

#### Key Requirements:
- Start with orange ✦ icon for character name
- Include both strengths and weaknesses
- Always provide scripture references
- Focus on character development
- Make lessons practical for modern life
- Use ↗ for sections and • for bullet points only

#### Key Requirements:

### 6. ❓ **Quick Q&A** (`qa`)
**Purpose:** Ultra-fast, direct answers to Bible questions with scripture support  
**Word Limit:** 100 words (ultra-fast)  
**Tone:** Direct, clear, helpful

#### Response Structure (4 Sections):
```
✦ [Question Topic]

↗ Answer
[Clear, direct response in 1-2 sentences]

↗ Scripture
[One relevant Bible verse with text and reference]

↗ Why
[Brief connection explanation in 1 sentence]
```

#### Key Requirements:
- Start with orange ✦ icon and topic title
- Keep responses under 100 words for speed
- Answer the specific question asked
- Always include one supporting verse
- Avoid theological complexity
- Be practical and applicable
- Clean formatting: ✦ ↗ • only

#### Example:
```
✦ ANGER & SIN

↗ Answer
Yes, anger itself isn't sinful - even Jesus got angry (Mark 3:5).

↗ Scripture
Ephesians 4:26 - "Be angry and do not sin; do not let the sun go down on your anger."

↗ Why
This shows anger can be righteous when directed at injustice, but shouldn't control us.
```

## 🎨 **SYMBOL USAGE RULES**

### Allowed Symbols:
- **✦** (orange star) - Main title/header
- **↗** - Section headers
- **•** - Bullet points within sections
- **✮** - Enhanced mode title (enhanced-chat only)

### Prohibited:
- ❌ Hashtags (#)
- ❌ Asterisks (*)
- ❌ Markdown formatting
- ❌ Decorative background shapes around icons
- ❌ Complex symbols or emojis

---

## 🔑 **KEY PRINCIPLES**

1. **Biblical Accuracy:** All responses must maintain orthodox biblical interpretation
2. **Scripture References:** Always include chapter:verse format when citing verses
3. **Clean Formatting:** Use only approved symbols (✦ ↗ •)
4. **Practical Application:** Connect biblical truth to real-life situations
5. **Speed Optimization:** Word limits enforced for fast responses
6. **Accessibility:** Avoid complex theological jargon, use clear language
